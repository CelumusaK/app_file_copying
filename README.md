# 🌊 Vibe Workspace

Vibe Workspace is a custom multi-pane project explorer built with Python and PyQt6. It is specifically designed to accelerate workflows for developers who frequently work with Large Language Models (LLMs). 

It allows you to view multiple projects side-by-side, quickly gather and copy file contents or ASCII directory trees to your clipboard, track estimated token counts, scaffold new projects from text, and easily filter out files you don't want to see.

## ✨ Features
- **Smart Screen Splitting:** Open up to 4 project panels at once. One project takes 100% of the screen, two projects split 50/50 exactly.
- **Copy to LLM:** Instantly copy project ASCII trees or the actual contents of multiple selected files into your clipboard.
- **Token Estimation:** Automatically calculates roughly how many tokens your selected files will consume.
- **ASCII Scaffolding:** Paste an ASCII tree (e.g., generated by ChatGPT or Claude) and click "Generate" to instantly create the actual folders and files on your hard drive.
- **Advanced Filtering Rules:** Hide files by Exact Match, Starts With, Ends With, or Contains. Settings are saved locally (`vibe_settings.json`) and persist between sessions.
